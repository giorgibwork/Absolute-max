# DSH Go Minimal Ops — v5.4

## Principle

Minimal plugins. Boot survival > novelty. Measure effect size.

## Suggested default set

1. Open Plugin Market index (once)
2. One memory plugin (origin-aware policy)
3. MCP tools/manager
4. Skill/MCP panel
5. Optional force-compact if compatible

After **each** install: verify boot + plugin list. One insert at a time.

## Ban on default PATH

Domain bots, trading packs, unrelated engines, experimental batches.

## Health-check ticket

- Engine listening
- Credentials present (do not print secrets)
- Workspace writable
- Plugin list vs last-known-good
- OS_READY checklist

## Cordis

Prefer `dsh plugin` flows. Restate whole rows when hand-patching. Last change is guilty on boot failure.

## Substrate

Phone = Router + light Worker. Heavy work → remote Worker under same Absolute Max law.  
Audit DSH-Android only on measured suite win — not fashion.
