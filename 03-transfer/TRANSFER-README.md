## For Custom GPTs (ChatGPT)
1. Create or edit a Custom GPT.
2. Go to Configure → Instructions.
3. Paste the **entire** contents of `GPT-8K-INSTRUCTIONS.md`.
4. Save. That is the complete Absolute Max + MRIP + structure-aware + ADHD system compressed under the 8k limit.

## For Claude / Gemini / Grok / local models
Use `PASTE-ME-MASTER.md` (or load absolute-max.md + MRIP_v3.md separately).
